# テクニック台帳

プレイヤーが使えるテクニックの一覧です。テクニックは**特別な処理を書かず、ルールから自然に生まれるもの**にします。

ルールや調整値を変えたときは、この表の「必要なルール」列を見て、どのテクニックが壊れるか確認します。

## 状態の凡例

| 記号 | 意味 |
|---|---|
| 未 | 未検証 |
| 成 | 実機で成立した |
| 楽 | 成立して、しかも楽しい |
| 没 | 不採用（理由をメモ欄に書く） |

「P0」列：○ ＝ 磁力おもちゃ（P0）で試せる、× ＝ 追加のルールやギミックが必要

## 追加候補（環境ギミックと組み合わせるもの）

- 極を持つ天井に張り付いて歩く
- 磁石ブロックを投げる

- 極プレートの発射台
- 磁石台車を押す

## 新しいテクニックを追加するとき

1. このルールから、あのテクニックが生まれる、という形で書く（特別な処理を足さない）。
2. **必要なルール**の列を必ず埋める。
3. プレイテストで偶然見つかったものも、ここに記録する（発見者と日付をメモ欄に）。

## 形ごとの傾向（観察メモ）

| 形 | 傾向 | 出典 |
|---|---|---|
| 丸 | 踏ん張れない。同じ極で近づくと転がって押し流されるので、発射台に向かず弾向き | 自動テスト 2026-09-24 |
| 四角 | 地上で踏ん張れるので発射台向き。転がると倒れながら進むので遅い | 自動テスト 2026-09-24 |
| 丸（着地） | 着地しても転がり落ちやすく、狭い棚や岸に止まれないことが多い | 自動テスト 2026-09-24 |
