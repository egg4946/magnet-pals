# プロトタイプ仕様書 P0「磁力おもちゃ」

最終更新: 2026-09-24

## 1. このプロトタイプで答えを出す問い

| # | 問い | 判断材料 |
|---|---|---|
| Q1 | 目的がなくても、2人が磁力で10分間遊び続けるか | 自発的に遊んだ時間、笑った回数、「せーの」が出たか |
| Q2 | 発動方式A（トグル・常時発動）で、動きたいのに動けない不快感が出すぎないか | 「勝手に飛ばされた」という不満の数 |
| Q3 | 回転ありと形どおりの当たり判定のカオスが、笑いになるか、イライラになるか | 失敗を「笑える失敗」と「ストレスな失敗」に分けて数える |
| Q4 | 形の違い（□○☆棒C字）で遊び方が変わるか | 形を変えたときに攻略法や役割が変わったか |
| Q5 | 操作体系は成立するか | キー同時押しの限界、マウスのサイドキーでの操作感 |

**やめる判断の基準**：数値を調整しても Q1 が満たせない場合は、ステージ制作に進まず、ゲームデザインを見直します。

## 2. 確定している仕様

- 磁力は**A方式**：各プレイヤーが極（N/S）をトグルで切り替え、磁力は常に発動している。同じ極なら反発、違う極なら引力。
- 2人は**同じルールで動くキャラ**。違いは形と入力デバイスから生まれる。
- キャラは**剛体（RigidBody2D）**。**回転あり**。**当たり判定は形どおり**（凹んだ形も含む）。
- 入力は1人4つ（左・右・ジャンプ・極切り替え）。
- **1画面の部屋制**。どちらかが落ちたら、2人とも即リスタート。
- 描いた形で遊ぶことが最終目標。そのため、**形は最初から多角形データ**として扱う。プリセット形状と、F4 で描いた形のどちらでも遊べる。

## 3. 磁力ルール

```
関係   = 1Pの極 × 2Pの極         （+1 = 反発, -1 = 引力）
距離 d = 2人の重心間の距離
減衰   = (1 − d / 作用範囲) ^ 減衰の鋭さ     … d ≥ 作用範囲なら 0
力     = 磁力の強さ × 減衰 × 立ち上がり × 関係
向き   = 2人の重心を結ぶ線
```

- **作用・反作用**：2人に同じ大きさで逆向きの力が働く。
- **接地アンカー**：地形の上に立っている方は、受ける力が `anchor_factor` 倍（初期値 0.2）になる。相方の上に乗っているだけでは踏ん張れない。この仕様により、肩車からの発射が成立する。
- **立ち上がり**：関係が切り替わった瞬間は力が0で、`ramp_time` 秒かけて最大になる。連打で物理が破綻するのを防ぐ。
- **くっつき反転**：2人が接触した状態で、関係が引力から反発に変わった瞬間、`burst_speed` の速度で弾け飛ぶ。同時にランダムな回転 `burst_spin` がかかる。再使用までの待ち時間は `burst_cooldown`。
  - 接触の判定には6pxの余裕を持たせる。地上どうしだと、摩擦のために数px手前で止まり、物理的には接触しないことがあるため。
  - 弾ける速度にも接地アンカーがかかる。2人とも地上にいると弱く弾け、片方が空中にいればその人が大きく飛ぶ。
- **速度上限**：`max_speed` を超えない。ポンピングで無限に加速するのを防ぐ。
- 磁力は壁を通り抜ける。磁力を遮る素材は P0 では扱わない。
- 力は重心に働くので、磁力そのものでは回転しない。回転は、衝突・転がり・くっつき反転から生まれる。
  - 設計意図：**飛んでいく軌道は読める。着地は読めない。**

## 4. 移動とジャンプ

- **地上**：左右入力で、目標の回転速度（`roll_spin`）に向けて回転を加える。同時に少しだけ横向きの力（`move_accel`）を加える。丸は転がり、四角はパタパタ倒れながら進む。
- **空中**：左右入力で回転を加え（**空中姿勢制御**）、少しだけ横方向にも動ける（`air_control`）。
- **ジャンプ**：地形でも相方でも、何かに触れていればジャンプできる（天井だけは除く）。触れなくなってから `coyote_time` 秒の猶予がある。
  - ジャンプの向き = 真上と「接している面から離れる方向」を `jump_normal_blend` の割合で混ぜた向き。これで壁キックが自然に生まれる。
  - 猶予時間中のジャンプも、最後に触れていた面の向きで跳ぶ（壁から離れた直後に真上へ跳べる抜け道をふさぐため）。
  - `jump_normal_blend` は **0.6**。壁キックは斜め上へ少し跳ぶだけで、**1人で壁を登ることはできない**。引力で壁に引き寄せられている間なら、壁キックを繰り返して登れる（技 B08）。
    - 0.5 以下にすると、壁キックの連打だけで1人で壁を登れてしまう。
    - 0.75 以上にすると、引き上げられる側が壁に張り付いたまま登れなくなる。
    - どちらも自動テストで確認済み（2026-09-24）。
  - 相方を踏み台にしてジャンプすると、反作用で相方が押し下げられる（`jump_reaction`）。
  - ジャンプボタンを早く離すと、上昇速度に `jump_cut` を掛ける（小ジャンプ）。

## 5. 形

- プリセットは「四角」「丸」「三角」「星」「棒」「C字」「L字」の7種類。
- 各形は**重心を原点に移し、面積を 2400px² にそろえる**。質量はすべて1。
- 描画は塗り（極の色：N=赤、S=青）、輪郭（1P=白、2P=黄）、目（相方の方を見る）。
- 当たり判定は、凹んだ多角形をGodotが自動で凸型の部品に分割したもの。高速で動いても衝突を取りこぼさないよう、連続衝突判定を有効にする。

### お絵描き（F4）

最終目標の「自分で描いた形で遊ぶ」機能。

- **F4** でお絵描き画面を開く。1P・2P の描画欄が左右に並び、それぞれ**一筆書き**で描く。
  - マウスで描く。キーボード担当はノートPCのタッチパッドで描ける。
  - 開いている間はゲームを一時停止する。
  - `Enter` で完成、`Esc` / `F4` でやめる。
- **書き始めの近くで描き終えると閉じた形**、離れた所で終えると**線に太さを付けた形**になる。
  - 太さは線の長さの1/8以上にして、極端に細い形を防ぐ。
- 線が交差していても（8の字、ぐちゃぐちゃ書き）、外周をたどった1つの形にまとめる。穴は埋まる。
- **インク量**：一筆の長さは1400pxまで。ゲージで残量を表示する。
- 変換後はプリセットと同じ扱いにする。
  - **面積を2400px²にそろえる**。
  - 重心から一番遠い点までの距離が70pxを超える場合は縮める（長い棒で奈落に橋を架けられないように）。
  - 頂点数は40までに減らす。
- ボタンを離した瞬間にゲームでの見た目（拡大）と「実際の大きさ」をプレビューする。形にできなかったときはメッセージを出す。
- 完成すると2人の形に反映して部屋をやり直す。背の高い形は、床にめり込まないよう出現位置を持ち上げる。
- 描いた形は `user://drawings.cfg` に保存し、次に起動したときもその形で始まる。F1 パネルの形の一覧から「描いた形」とプリセットを切り替えられる。
- 変換処理は `ShapeLib.from_stroke`。流れは次のとおり。
  1. 折れ線を間引く（RDP）
  2. Godot の `Geometry2D.offset_polyline` で線に太さを付け、一番外側の輪郭を取る
  3. 頂点を減らす
  4. `offset_polygon` でもう一度外周を取り、自己交差をなくす
  5. 面積と大きさをそろえる
  6. 三角形分割と凸分解ができるか確かめる

## 6. 操作

| 入力 | キーボード WASD | キーボード 矢印 | マウス | パッド |
|---|---|---|---|---|
| 左 | A | ← | 左クリック | 左スティック / 十字キー |
| 右 | D | → | 右クリック | 左スティック / 十字キー |
| ジャンプ | W | ↑ | サイドキー上（進む）/ ホイール上 | A |
| 極切り替え | S | ↓ | サイドキー下（戻る）/ ホイール下 | B / X / RB |

- 初期設定は 1P＝WASD、2P＝マウス。F1 のパネルでデバイスを変更できる。
- キーは物理位置で判定するので、JIS配列でもUS配列でも同じ場所のキーで操作できる。
- マウスを使うプレイヤーがいる間は、カーソルを非表示にしてウィンドウ内に閉じ込める。F1 パネルを開いている間はカーソルを戻し、マウス担当の入力を止める。
- サイドキーの上下が逆のマウスは、パネルのチェックボックスで入れ替えられる。
- 共通キー：`F1` 調整パネル、`F4` お絵描き、`R` / `Backspace` やり直し、`F2` / `F3` 前／次のステージ。クリアすると自動で次のステージへ進む。

## 7. ステージ（各1280×720の1画面）

ステージのデータは `scripts/stages.gd` にある。左右の画面端の壁は共通で追加される。
**2人ともゴール枠に入るとクリア**になり、3秒後に次のステージへ進む。
開始位置は、2人を作用範囲（260px）より離して置く。

### ステージ設計の前提（2026-09-24 に自動テストで計測）

| 技 | 実測 | ステージ設計への影響 |
|---|---|---|
| 送り出し | 2人の間隔で飛距離が変わる。くっついていると約1100px、間隔130で約810px、間隔170で約590px、間隔210で約380px、間隔250で約200px | 広い足場からなら**力加減**で狙った所に着地させられる。狭い足場からは間隔を空けられず全力になる |
| 肩車発射 | 床から約660px（ジャンプを合わせると1000px超） | 1人を上へ送るのは簡単。天井で制限する |
| つり上げ | 高さ300pxの崖まで登れる（350pxは無理） | 2人目を上げられる高さが、段差の上限を決める |
| 迎え入れ | 同じ高さなら約310pxの奈落を越えられる | 奈落の幅の上限 |

**宙に浮いた薄い足場の上には、つり上げができない**（下の人が足場の裏に張り付く）。そのため、つり上げで登らせたい高台は、地面から続く崖にする。

### ステージ1：奈落

```
                                             ┌────────┐
                                             │  GOAL  │
                     ▭ 上空の足場             ├────────┤ 高台（崖。y=330）
 ▭ 小足場                                     │        │
 1P    2P                                     │        │
━━━━━━━━━━━━━━┓     奈落 310px      ┏━━━━━━━━┷━━━━━━━━┥
              ┃                      ┃
```

- 奈落の幅は **310px**（x 460〜770）。自動テストで測った次の3点を満たす幅として選んだ。
  - 通常ジャンプだけでは越えられない（到達は x≈709 まで）
  - 送り出しなら越えられる
  - 迎え入れなら越えられる
- ゴールの高台は、地面から続く高さ270pxの崖。
- 想定の解き方：送り出しで奈落を越える → 迎え入れで相方を渡す → 肩車発射で1人が高台へ → つり上げで相方を高台へ。

### ステージ2：崖と天井

```
                                                     ┌──────┐
                                                     │ GOAL │
                    ┌───天井───┐                     ├──────┤ 棚（崖の上から+210px）
                                        ┌────────────┘
 1P       2P                            │ 崖（高さ270px）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┷━━━━━━━━━━━━━━━━━━━━
```

- 狙い：**打ち上げ**（肩車発射・送り出し）と**つり上げ**を、2段で2回ずつ使わせる。
- 崖の縁の真上に天井が張り出していて、真上に打ち上げると頭をぶつける。
- 奈落がないので落下によるやり直しは起きない。落ち着いて「上げる」「引き上げる」を練習できる。
- 棚へは、送り出しでは届かない（下から棚の裏にぶつかる）。肩車発射か、つり上げを使う。

### ステージ3：飛び石

```
                                                          ┌──────┐
                                                          │ GOAL │
                                                ┌─────────┴──────┤ 岸（柱から+80px、右の壁が受け止める）
                               ┌──────┐         │
 1P          2P                │  柱  │         │
━━━━━━━━━━━━━━━━┓   奈落 250   │幅130 │ 奈落210 │
                ┃              │      │         │
```

- 狙い：送り出しの**力加減**。
  - 広いスタート地面からは、間隔を調整して、狭い柱（幅130）にぴたりと着地させる必要がある。自動テストでは、間隔190前後だけが成功した。
  - 柱の上は狭くて間隔を空けられないので全力の送り出しになるが、次の岸は右の壁が受け止めてくれる。
- どちらの段も、先に渡った方が迎え入れで相方を連れてくる。
- 柱の上で送り出すとき、送る側が踏ん張ろうとして右キーを押すと、自分が歩いて柱から落ちることがある（笑える失敗の候補）。

### 磁力の初期値の決め方（2026-09-24 に自動テストで計測）

どちらも四角どうしで計測。「地上の滑り」は、地上で隣り合って反発したときに2人が1秒で動いた距離の合計。

| 強さ | 範囲 | 減衰 | 送り出し | 迎え入れ | 地上の滑り |
|---|---|---|---|---|---|
| 2600 | 200 | 1.0 | × | × | ― |
| 4000 | 260 | 1.0 | ○ | × | 2px |
| **4000** | **260** | **0.6** | **○** | **○** | **5px** |
| 4500 | 260 | 0.7 | ○（余裕あり） | ○ | 17px |
| 5500 | 260 | 1.0 | ○（余裕あり） | ○ | 52px（勝手に滑る） |

強くしすぎると、地上にいるだけで相方に押されて滑るようになる（動けない不快感が増える）。そのため、送り出しと迎え入れが**ぎりぎり成立する**値を初期値にした。

## 9. 画面表示

- 各プレイヤーの作用範囲を円で表示する（極の色）。
- 範囲内にいる間は、2人の間に磁力線を表示する（引力＝紫、反発＝黄）。線の太さが力の強さを表す。
- 頭上に「1P N」のようなラベルを出す。画面より上に飛び出したら、上端に矢印と高さを表示する。
- 左上：デバイス、極、関係、経過時間、やり直し回数。
- 左下：**今押されているキーの一覧**（キー同時押しの限界を確認するため）。

## 10. プレイテスト手順

1. **（初日）キー同時押しの確認**：1P と 2P が同時に「移動＋ジャンプ＋切り替え」を押し、左下の一覧に全部表示されるか確認する。共有キーボードの組み合わせ（WASD＋矢印）でも確認する。
2. **自由に遊ぶ（10分）**：ゴールの話はせず、「磁石になれるよ」とだけ伝えて観察する。
3. **ゴールを目指す**：時間と、やり直し回数を記録する。
4. **形を変える**：同じ部屋を、形を変えて遊んでもらう。
5. **数値を変えて比較する**（1回につき1項目だけ）：
   - `anchor_factor` を 1.0 にする（アンカーなし）
   - `burst_speed` を 0 にする（くっつき反転なし）
   - `angular_damp` を 5 にする（回転がすぐ止まる）

### 自動テスト

どちらも `--fixed-fps 120` を付けると、実時間より速く回る。

```
godot --headless --fixed-fps 120 --path . res://tests/smoke_test.tscn
godot --headless --fixed-fps 120 --path . res://tests/stage_test.tscn
```

**stage_test**（ステージの攻略手順テスト）は、各ステージの攻略手順を1ステップずつ再現する（約1分半）。
- 磁力を使った手順が成立すること、自力ジャンプだけでは突破できないことを確かめる。
- 合否は四角どうしの結果で判定する。丸の結果は参考値として出力する。
- 引数で調整値を上書きして試せる。例：`-- jump_normal_blend=0.8 only_square`
- ステージや調整値を変えたら必ず実行する。

**smoke_test** は、キー入力を擬似的に送り、次の項目を確認する。
- 着地と移動
- 通常ジャンプの高さ
- くっつき反転
- 奈落越え（通常ジャンプ／送り出し／迎え入れ）
- 全形状の生成
- お絵描き（いろいろな一筆の変換、画面の操作での反映、描いた形で床に立てるか）
- 落下したときのリスタート

### 自動テストで分かったこと（2026-09-24）

- **丸は踏ん張れない**：同じ極で近づくと、転がって押し流される。発射台には四角など平らな形が向く。形による役割の違いが、特別な処理なしに生まれている。
- **迎え入れの実態**：迎え入れは「空中で引き寄せる」より、「奈落の壁に叩きつけられたあと、引力で壁をズルズル引き上げられる」形で成立することが多い（技 A10）。登り切るまで2〜4秒かかる。
- **壁に張り付く**：引き上げる側が足場の奥に立つと、引力がほぼ横向きになって、下の人が壁に押し付けられたまま止まる。ジャンプを連打すれば、壁キックと引力の繰り返しで登れる（技 B08）。
- **丸は着地で転がる**：丸は棚や岸に着地しても転がり落ちやすく、肩車発射や全力の送り出しで狭い場所に止まれないことが多い。
- **試して取り消した変更**：「床は滑らず、壁は滑る」地形（壁の摩擦を小さくする）を試した。引力で壁に押し付けられた四角は、壁との摩擦で転がって登っていたので、壁が滑ると登れなくなった。そのため取り消した。

## 13. 既知のリスク

- **地形への挟まり**：凹んだ形は地形に噛み込むことがある → `R` / `Backspace` でやり直す。発生回数を記録する。
- **すり抜け**：細い形が高速で飛ぶとき → 連続衝突判定で対策済み。発生したら記録する。
- **マウスのサイドキー**：マウスのユーティリティソフトが別の機能に割り当てていると反応しない。左下のキー一覧で、入力が届いているか確認できる。
- **ノートPCのキーボードのゴースト**：手順1で確認する。
